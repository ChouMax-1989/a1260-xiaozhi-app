# A1260 小智 APP

这是给 A1260 做的一款小智语音聊天 Android 客户端。它可以打字提问、按住按钮说话，也可以先在本机设置唤醒词，喊出唤醒词后再提问。**AI 问答需要联网和自己的小智账号；设备里没有离线运行的大模型。**

目前在 **Android 11、ARMv7 的 A1260** 上做过安装和使用测试。其他 Android 设备能否正常使用，尚未保证。

## 下载和安装

从 [最新版本下载 APK](https://github.com/ChouMax-1989/a1260-xiaozhi-app/releases/latest)，复制到 A1260 后打开安装。首次使用按系统提示授予麦克风权限；若要使用持续监听的本地唤醒，还需允许相关通知。

首次打开会显示绑定提示和六位设备码。请登录自己的 [小智官方控制台](https://xiaozhi.me/console/agents)，按页面的正常流程把设备加入智能体并输入设备码。绑定成功后，APP 会使用服务端下发的连接配置。**本项目不提供账号或绑定绕过。**

## 快速使用

1. 等主界面状态显示在线。在输入框打字，点“发送”即可提问。
2. 点输入栏的“语音”，切到语音按钮；**按住说话，松开发送**。需要录音权限。
3. 想免按键唤醒时，打开右上角“更多”→“本地唤醒”，保存中文唤醒词，按提示录制并验证三遍，再点“开启本地唤醒”。听到唤醒提示音后再说问题。这个开关可在同一页面关闭。

唤醒词在本机识别；**唤醒后的问题仍会通过网络发给小智服务器处理**。具体步骤、设置和常见问题见 [使用说明](docs/USAGE.md)。

## 两个容易混淆的时间设置

在右上角“更多”→“设置”里可以分别调节并保存：

| 设置 | 管哪一段等待 | 默认值 | 可调范围 |
| --- | --- | --- | --- |
| 说完后多久发送 | 唤醒后说话，停顿多久才提交这句话 | 0.6 秒 | 0.4–2 秒 |
| 回答后等待追问 | 服务器回答播完后，留多久让你直接接着问 | 0.5 秒 | 0.5–10 秒 |

调短第一个设置可能把一句话中间的停顿当作说完。第二个设置只用于唤醒词开启的对话；超时后播放结束提示音，再回到等待唤醒。按住说话不使用这个追问窗口。

## 其他功能与限制

“更多”菜单里还有音乐、功能 / 插件、停止和设备自检。本地音乐可选择设备上的音频和 LRC 歌词；功能与插件页提供音量、媒体按键、设备信息及应用白名单等内置工具。媒体按键能否控制播放取决于系统当前播放器；只有你勾选的应用才会进入可启动白名单。工具是否可用还取决于系统权限和服务器会话，不能仅凭页面上有按钮判断它在每台设备上都有效。

网络和服务器处理会影响回答速度。两次 A1260 简单问答测试中，**问题提交到收到首个语音数据包约 3.39–4.24 秒**，主要时间花在网络和服务器等待；实际听到回答还要加上说完后的停顿确认与本地播放时间。本机处理通常只是几十到几百毫秒，测试结果不代表每次都能达到相同速度。实验性的全双工模式没有声学回声消除，默认关闭，扬声器声音可能重新被麦克风收进去。

如果连接中断，APP 会尝试恢复；仍未连上时，检查网络、账号绑定和服务器状态，再从“更多”点“连接”。想结束当前对话可点菜单中的停止项；要停止持续监听，请到“本地唤醒”点“停止本地唤醒”。
